# Bravura

SMuFL(Standard Music Font Layout) 레퍼런스 악보 폰트입니다. 오선지 UI의 음자리표·조표·박자표에 씁니다.

- 출처: https://github.com/steinbergmedia/bravura
- 라이선스: SIL Open Font License 1.1 (`LICENSE.txt`). **제거하지 않습니다.**
- `Bravura.otf` — 네이티브(`expo-font`)
- `Bravura.woff2` — 웹(`@font-face`)

두 파일은 같은 폰트라 플랫폼 간 글리프가 어긋나지 않습니다.
배치 규약과 사용법은 리디자인 보고서 4.7.6 · 5.7절에 있습니다.
